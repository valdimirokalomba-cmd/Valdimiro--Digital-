Como Funciona?

O processo foi pensado para ser simples.

1. Envia a tua música

Preenche o formulário com os dados do artista e do lançamento.

2. Enviamos para análise

Os dados e materiais enviados são analisados antes do processo de distribuição.

3. Preparação do lançamento

Organizamos as informações necessárias para o lançamento.

4. Distribuição

O lançamento é encaminhado para os serviços digitais compatíveis com o processo utilizado.

5. Acompanhamento

O artista recebe informações sobre o andamento do lançamento.
